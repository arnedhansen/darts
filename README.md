# Darts Scorer

Offline-capable PWA for scoring **301**, **501**, and **Cricket** (up to 4 players).

## Run locally

```bash
npm install
npm run dev
```

## Test / build

```bash
npm test
npm run build
npm run preview
```

## Install on iPad

1. Open the deployed URL in **Safari**
2. Tap **Share** → **Add to Home Screen**
3. After the first visit it works offline

## Features

- 301 / 501 with optional double-out
- Standard cricket (15–20 + bull)
- Undo, end turn early, soft button sounds
- Resumes an in-progress match after closing the tab
